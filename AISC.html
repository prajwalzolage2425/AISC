Exp 2 · Agent Architecture

Theory experiment: discuss a suitable agent architecture for the chosen problem (no code).

Steps

  1. Take the problem selected in Exp 1.
  2. Study the agent types: simple reflex, model-based reflex, goal-based, utility-based, learning agent.
  3. Choose the suitable architecture and justify it.
  4. Draw the diagram (Sensors → Condition-action rules → Actuators) and write the conclusion.

Agent types

Simple reflex Acts on the current percept using condition-action rules
Model-based reflex Keeps an internal state of the world
Goal-based Chooses actions that reach a goal
Utility-based Picks the best action by maximizing utility
Learning agent Improves its performance from experience
For the vacuum cleaner problem a Simple Reflex Agent is suitable: if the current square is dirty then Suck, else move to the other square.

Exp 8 · Perceptron: AND, OR, XOR

Train a single-layer perceptron; it learns AND and OR but fails on XOR (not linearly separable).

Steps

  1. Open Jupyter Notebook / JupyterLab (or Google Colab). NumPy must be available (pip install numpy).
  2. Create notebook A27_Exp8_AISC.ipynb and paste the code in one cell.
  3. Run the cell (Shift+Enter).
  4. Compare Expected vs Predicted: AND and OR match, XOR does not. Screenshot code and output.
AND and OR predictions equal the expected values. XOR shows at least one mismatch, proving a single-layer perceptron cannot learn XOR; a multilayer perceptron with a hidden layer is needed.
