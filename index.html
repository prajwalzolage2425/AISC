Machine Learning / Data Analytics & Statistics Practical

11 experiments · theory · steps · code you can paste cell by cell into JupyterLab · dataset table + CSV · output

Run in JupyterLab (try-jupyter)

  1. Open jupyter.org/try-jupyter/lab and click Python (Pyodide) under Notebook.
  2. Cell 1: paste the install cell of the experiment (%pip install -q …) and run it with Shift+Enter (once per notebook).
  3. Cell 2 (data): either upload the CSV with the Upload button in the left file browser, or click Copy file-creation cell in the Dataset section, paste it in a cell and run it – the CSV is created for you.
  4. Cell 3: paste the experiment code and run it. Graphs appear below the cell.
  5. Download your notebook (File → Download) before closing the tab, because try-jupyter does not save files permanently.
